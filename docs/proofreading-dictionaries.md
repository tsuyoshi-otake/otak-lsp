# 校正用・ルールJSON辞書

`otakLsp.proofreading.dictionaries.proofreading` にJSONファイルのパスを設定すると、その辞書に一致した箇所を診断します。絶対パス、または解析する文書のフォルダーからの相対パスを指定できます。設定できるファイルは最大5つ、各ファイルは2 MiB以下です。

辞書はJSON配列で、各項目の `match` が対象文字列です。`mode` を省略すると指定文字列と一致する部分を検出し、`regex` を指定すると正規表現で一致します。`category` は診断コード `dictionary-<category>` に使用します。`replace` と `message` は省略できます。

```json
[
  { "category": "term", "match": "表記例", "replace": "推奨表記" },
  { "category": "rule", "match": "[0-9]+個", "mode": "regex", "message": "個数の表記を確認してください" }
]
```

各文書の設定で辞書を選び、次の解析でファイルを読み直します。読込失敗や実行期限超過は `dictionary-check-failed`、辞書診断を1000件で打ち切った場合は `dictionary-truncated` のHintとして文書先頭に表示します。正規表現は別のWorkerで実行し、Workerの待機時間を含め5秒で終了しない場合は停止します。この期限はファイル読込時間には適用されません。Workerの処理に失敗した場合、他の文法診断は続行しますが、辞書診断は得られません。空文字やゼロ幅の一致は診断しません。

Markdownの除外範囲や、コード言語のコメント以外をまたぐ一致は診断しません。Markdown表内は `otakLsp.markdown.analyzeTables` の設定に従います。

## ルール辞書

`otakLsp.proofreading.dictionaries.rule` に最大3つのJSONファイルを指定します。各ファイルは2 MiB以下、相対パスは対象文書のフォルダーを基準にします。`otakLsp.proofreading.rule.enable` でルール辞書だけを有効・無効にできます。既定値は有効ですが、辞書を指定しなければ検査は行われません。

```json
[
  { "pattern": "禁止[0-9]+", "message": "独自ルールに一致しました", "severity": "warn" },
  { "pattern": "要確認", "message": "内容を確認してください", "severity": "info" }
]
```

`pattern` は正規表現、`message` は診断メッセージです。`severity` を省略すると警告となり、`info` なら情報として表示します。診断コードは `dictionary-rule` です。実行時間と診断件数の上限は辞書種別ごとに適用し、一方の辞書の失敗は他方の辞書を止めません。空のパターン、構文が無効な正規表現、必須項目が不正なエントリは通知し、他の有効な項目は検査します。

## スペル検査と追加辞書

`otakLsp.proofreading.spell.enable` を有効にすると、同梱の米国英語辞書を使い、辞書外の英小文字3文字以上を情報として示します。既定では無効です。`spell.checkUppercase` を有効にすると先頭のみ大文字の語、`spell.checkAllCaps` を有効にするとすべて大文字の語も検査します。どちらも既定では無効です。最大3件の候補を表示しますが、未知語すべてが誤字とは限らず、技術用語、略語、固有名詞も指摘されることがあります。途中に大文字がある語、数字・識別子・ハイフン・短縮形の一部分、URLとメールアドレスは現在検査しません。長さ24文字を超える語の候補は生成しません。

既存の用語表記辞書にある正規表記のうち、英字だけの語はスペル検査で受け入れます（例: `nginx`、`Nginx`、`NGINX`）。大文字小文字以外に違いがある誤表記は正規表記として取り込みません。これはスペル検査であり、大文字小文字の表記統一は判定しません。記号や空白を含む正規表記は単語として追加しません。

`tsconfig.json`、`src/config.yaml`、`.env` など、よく使われる拡張子やドットファイルの名前はスペル検査と繰り返し検査から除外します。未知の拡張子や空白を含むファイル名など、すべてのパスを判別するものではありません。文末の `reasearch.` などは引き続き検査します。

`otakLsp.proofreading.dictionaries.spell` に最大3つの単語リストを指定すると、対応する文書の辞書に追加されます。各ファイルは2 MiB以下、相対パスは対象文書のフォルダーを基準にします。1行1単語とし、空行と `#` で始まる行は無視します。次の解析でファイルを読み直します。読込失敗は通知し、基礎辞書の検査は続行します。辞書処理はWorkerで実行し、待機を含め5秒の期限と1000診断の上限を適用します。ファイル読込時間は期限に含まれません。

スペル検査が有効なとき、`otakLsp.proofreading.spell.checkRepeat` は、同じ行で空白またはタブだけを挟んで連続する英単語を検出します。2文字以上が対象で、大文字と小文字の違いは区別せず、2語目を指摘します。句読点や改行、Markdownのコードなどの除外範囲をまたぐ繰り返しは対象外です。既定では有効ですが、スペル検査全体が無効なら実行しません。

スペル機能のその他の細かなオプション、文頭・句読点・スペースの検査、日本語名称辞書の候補切替、独立したユーザー辞書スロットは未実装です。
