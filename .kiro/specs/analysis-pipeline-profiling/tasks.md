# 実装計画: 解析パイプライン計測ログ

## 概要

解析パイプラインの主要ステップを計測し、処理時間と比率をログ出力する。計測は `OTAK_LCP_PROFILE=1` でオプトインとし、無効時のオーバーヘッドを最小化する。

## タスク

- [x] 1. 計測フラグの追加
  - `server/src/main.ts` に `PROFILE_LOGS` を追加
  - 環境変数 `OTAK_LCP_PROFILE` を参照

- [x] 2. 計測ユーティリティの追加
  - ステップ計測用のヘルパー関数（開始/終了/集計）を実装
  - ログ整形（合計、割合、補足情報）を1ブロックで出力

- [x] 3. 解析パイプラインの計測
  - `analyzeDocument` に計測ポイントを追加
  - Markdownフィルタ、kuromoji、トークンフィルタ、基本/高度ルール、診断反映を計測
  - stale判定時は `stale=true` をログに含める

- [x] 4. セマンティックトークン生成の計測
  - `textDocument/semanticTokens/full` の生成処理を計測
  - キャッシュヒット/ミスをログに含める

- [x] 5. 手動確認の観点整理
  - `OTAK_LCP_PROFILE=1` 有効時にログが出ること
  - Markdown/非Markdownでのログ差異を確認

## 注意事項

- ログは日本語で出力する
- 計測が無効な場合は計測処理を実行しない
- 計測は解析結果に影響を与えない
